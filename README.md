# Waze User Churn Prediction

## Project Overview
This data science project analyzes user churn for Waze, a navigation app, to identify factors associated with users discontinuing their use of the app. It uses Exploratory Data Analysis (EDA), data visualization, regression analysis, and machine learning to uncover patterns in user behavior and predict potential churn.

## Objectives
- Explore and understand user behavior through EDA.
- Visualize trends and patterns related to user churn.
- Perform statistical and regression analysis to investigate relationships between variables.
- Develop a machine learning model to predict user churn.
- Generate insights that could help improve user retention and support data-driven business decisions.

## Key Techniques
- Exploratory Data Analysis (EDA)
- Data Visualization
- Statistical Analysis and Hypothesis Testing
- Regression Analysis
- Machine Learning and Churn Prediction

## Business Impact
The project aims to identify users who are more likely to churn and uncover factors associated with churn, helping Waze develop strategies to improve user retention and support business growth.

*Note: This project is an analytical case study based on the Waze business scenario, not an official Waze project.*
